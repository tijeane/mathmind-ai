# Learning

## Purpose

The learning domain defines the pedagogical foundation of MathMind. Documents here establish how the product teaches mathematics, how learners progress, and the instructional principles that govern content design and AI tutor behavior.

## Contents

This folder holds approved learning principles, curriculum frameworks, assessment strategies, and instructional design standards. Content in this domain directly informs product requirements, AI tutor prompts, and user experience decisions.
