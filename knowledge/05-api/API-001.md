# Executive Summary

This document defines the official REST API specification for the MathMind platform.

It standardizes endpoint design, authentication, request and response formats, versioning, error handling, pagination, filtering, and integration patterns.

This specification is the authoritative reference for all backend APIs.

---

# Objectives

The API should provide:

- Consistency
- Predictability
- Security
- Performance
- Backward compatibility
- Comprehensive documentation

---

# API Principles

The MathMind API follows these principles:

- RESTful resource design
- Stateless communication
- JSON payloads
- Semantic HTTP methods
- Versioned endpoints
- Secure by default
- Backward compatibility
- Consistent error handling

---

# Base URL

Development

```
/api/v1
```

Production

```
https://api.mathmind.ai/v1
```

Breaking changes require a new API version.

---

# Authentication

Protected endpoints require JWT authentication.

Example:

```
Authorization: Bearer <token>
```

Authentication is managed through Supabase Auth.

---

# Authorization

Role-Based Access Control (RBAC) applies to all protected resources.

Supported roles include:

- Student
- Parent
- Teacher
- School Administrator
- Platform Administrator

---

# Standard Response Format

Successful responses follow:

```json
{
  "data": {},
  "meta": {},
  "links": {}
}
```

---

# Standard Error Format

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid request.",
    "details": []
  }
}
```

# Pagination

Collection endpoints support:

```
?page=1

&page_size=25
```

Response metadata includes:

- page
- page_size
- total_items
- total_pages

---

# Filtering

Example:

```
GET /courses?grade=6
```

Multiple filters may be combined.

---

# Sorting

Example:

```

```

# Search
